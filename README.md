# Aditya Khiratkar — Developer Portfolio

Personal developer portfolio for **Aditya Khiratkar**, Computer Science undergraduate at **Symbiosis Institute of Technology (SIT)**.

Featuring algorithmic optimization, distributed systems, and real-time visitor telemetry with a custom warm cream editorial palette.

---

## 🛠️ Tech Stack

- **Framework:** [Next.js 16](https://nextjs.org/) (App Router)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Telemetry:** Client-side session and OS/device visitor intelligence

---

## 🚀 Featured Engineering Projects

1. **RouteOpt**
   - Commercial Fleet Route Optimization & AI Dispatch Simulator
   - Mixed-fleet CVRPTW solver using Google OR-Tools (1,200kg Tata Ace vs 4,500kg Tata 407).
   - Regional municipal regulations engine (MMRDA / Pune PMC peak hour bans, 2.5m flyover height limits).
   - Real-time Groq LLM (gpt-oss-120b) What-If disruption simulator.
   - [Repository](https://github.com/Sparsh566/RouteOpt)

2. **TenderBlock**
   - Decentralized Tendering & Trustless Procurement Platform
   - Cadence smart contract lifecycle on Flow Blockchain (tenders, bidding, settlement).
   - Sub-second off-chain MySQL read-model indexer.
   - IPFS / Web3.Storage decentralized audit manifests.
   - [Repository](https://github.com/Sparsh566/TenderBlock)


Open [http://localhost:3000](http://localhost:3000) to view the portfolio.
